# 在途 Onway

v0.2 个人旅行工具：创建行程，在地图上收集地点，再按天安排顺序。Web 与 Android 使用同一套 React 界面，各自保存本地数据，不连接 TREK 或业务服务器。

## 开发与构建

需要 Node.js 24、npm 11。

```powershell
npm ci
npm run dev
```

打开 [本地开发页面](http://127.0.0.1:5175/#/today)。端口固定，避免改变 IndexedDB 所属来源；localhost 与 127.0.0.1 也是不同的存储来源。

```powershell
npm run check
npm run format:check
npm run preview
npm run android:debug
```

Android 最低版本为 **Android 12（API 31）**，以个人手机使用为目标，不安排低版本兼容。Debug APK 生成在 `artifacts/onway-debug.apk`，当前应用版本 `0.2.0` / `versionCode 2`。

## 开始使用

1. 在“计划”页创建行程，填写名称和天数；出发日期可以留空。首次打开没有行程，也可以主动点击“创建示例行程”体验。
2. 在“地图”页点击底图空白处，填写地点名称与可选备注，保存到某一天或“未安排”。“全部”筛选下默认保存到未安排，筛选某一天时默认保存到该天。
3. 点击已有标记查看名称并编辑；可修改名称、备注、所属天，或重新在地图上选点。取消编辑不会创建地点。
4. 在“计划”页调整地点顺序、移动到其他天、追加天数或删除。删除某一天会将它的地点移回未安排，行程至少保留一天。
5. 在顶部行程选择器切换行程。“今天”显示日期对应的当天安排；日期未定或今天不在行程期间时，明确显示首日预览。

今天／地图／计划共享当前行程，地图与计划共享“全部／未安排／第 N 天”筛选。行程、地点表单需要点击保存；列表移动、排序等操作直接保存，成功后才更新各页面。保存失败保留草稿或原有列表，并显示重试提示。

“个人备注”独立保存，沿用 v0.1 的旧备注数据，不归入任何行程。离开今天页前请主动保存备注。

示例按钮会创建可独立编辑的三天行程副本；示例地点是公开城市中心的近似 WGS84 坐标，来源链接见地点详情和计划列表。它们不是景区入口或导航目的地。地图使用 MapLibre GL JS 与 OpenFreeMap Positron；自驾路线、距离和预计时间尚未接入，不展示模拟结果。

## 数据与离线

- Web 数据位于当前浏览器来源的 `onway-local` IndexedDB；APK 数据位于应用私有目录的 `onwaySQLite.db`。两端数据独立，均无账号或云同步。
- APK 内置页面资源。断网仍能打开页面，管理已有行程，修改已有地点的名称、备注、分天与顺序，以及保存个人备注。
- 底图在线加载，不保证离线可用。地图新增地点和重新选点需要可用底图；加载失败时仍可从列表编辑已有数据，恢复网络后重试地图。
- Web 没有 Service Worker，不保证断网冷启动；页面已打开后的本地存储操作不依赖网络。
- Web 多标签保存会检查旧快照冲突；若提示其他页面已更新，请重新加载后再修改。支持 Web Locks 的环境还会串行化跨标签写入，旧环境建议只开一个编辑标签。
- 清除网站／应用数据或卸载 APK 会删除本地资料。文件导入导出、备份尚未实现；覆盖更新 APK 需保持包名与签名一致，以保留已有数据。

当前不包含地点搜索、设备定位、道路算路、天气、AI、费用、协作、云同步、文件互导或离线地图下载。
