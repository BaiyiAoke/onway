# 在途 Onway

v0.3 个人旅行工具：创建行程、按天安排地点，手动计算自驾路线，并在 Android 上打开高德导航。Web 与 Android 使用同一套 React 界面，各自保存本地数据，不连接 TREK 或业务后端。

## 开发与构建

需要 Node.js 24、npm 11。

```powershell
npm ci
npm run dev
```

打开 [本地开发页面](http://127.0.0.1:5175/#/today)。端口固定；localhost 与 127.0.0.1 是不同的 IndexedDB 存储来源。

```powershell
npm run check
npm run format:check
npm run preview
npm run android:debug
```

Android 最低版本为 **Android 12（API 31）**，以个人手机使用为目标。Debug APK 为 `artifacts/onway-debug.apk`，应用版本 `0.3.0` / `versionCode 3`。

## 开始使用

1. 在“计划”页创建行程，填写名称和天数；出发日期可以留空。首次打开没有行程，也可以主动创建示例副本。
2. 在“地图”页点选位置，手动填写名称和备注，保存到某一天或“未安排”；已有标记可编辑或重新选点。
3. 在“计划”页调整地点顺序与所属天。删除一天会将地点移回未安排；行程至少保留一天。
4. 一天安排至少两个地点后，点击“计算自驾路线”。按地点顺序一次计算当天总里程、预计驾驶时间与相邻地点分段；不自动连接前一天的终点。
5. 地点增删、移动、重新选点或排序后，受影响日期显示“路线待更新”，手动点击重新计算。改名、改备注或改出发日期不会使路线失效。
6. 地图选择一天查看路线；“全部”显示各天仍有效的路线，各天之间不连接；“未安排”只显示地点。
7. 今天页显示当天已有估算；日期未定或不在行程期间时，继续明确标注首日预览。
8. Android 已保存地点可点击“高德导航”，由手机里安装的高德从当前位置规划。未安装或启动失败会提示；Web 不显示此按钮。

今天／地图／计划共享当前行程，地图与计划共享日期筛选。行程表单需要保存；列表移动和排序直接保存，成功后才更新页面。个人备注独立保存，沿用 v0.1 的旧备注键，不归入某个行程。

示例地点是公开城市中心的近似 WGS84 坐标，来源链接见地点资料；不是景区入口。地图使用 MapLibre GL JS + OpenFreeMap Positron。路线来自实际公共服务，不显示模拟里程或驾驶时间。

## 路线与高德的边界

- 点击计算会将当天地点坐标发送给 [FOSSGIS 公共 OSRM 服务](https://routing.openstreetmap.de/about.html)；不发送行程名称、地点名称或备注。成功结果保存在本机。服务端会记录请求日志，详见其使用及隐私说明。
- 请求串行执行，开始间隔至少 1 秒，20 秒超时，不自动重试。地点最多吸附到 1 公里内的可驾车道路；无道路或无法连通时，需要检查地点位置。
- 结果标明计算时间和来源，属于驾驶估算，不含停留时间、实时路况或收费。公共服务可能不可用，失败不影响本地行程编辑。
- 新结果写入失败会标注未保存并允许“重试保存路线”，无需再请求网络；读取异常保留原缓存，不覆盖为空。
- 高德收到已保存地点的名称和 WGS84 目的地坐标；Onway 不读取设备定位。实际导航由高德根据当前位置及其偏好重新计算，可能不同于 Onway 的估算。接入依据：[高德 Android 导航 URI](https://lbs.amap.com/api/amap-mobile/guide/android/navigation)。

## 数据与离线

- Web 使用当前浏览器来源的 `onway-local` IndexedDB；APK 使用应用私有目录的 `onwaySQLite.db`。两端数据独立，无账号和云同步。
- 原数据库 v1、`travel.workspace` 文档 v1 和旧备注键保持不变；新增独立 `routes.cache` 文档保存各天最近一次成功的路线。
- APK 内置页面资源。断网可管理已有行程、地点与备注，并读取仍匹配的路线缓存；不能离线重新算路。
- 缓存不包含底图。地图、瓦片和字体仍需联网，不承诺离线可用；加载失败时仍可从列表编辑地点。
- Web 没有 Service Worker，不保证离线冷启动或离线加载尚未下载的按需模块；已加载页面中的本地存储操作不依赖网络。
- Web 多标签写入保留旧快照冲突保护；建议在一个标签里编辑。路线请求限速为当前应用实例内的队列。
- 清除网站／应用数据或卸载 APK 会删除本地资料。备份和文件互导尚未实现；覆盖安装必须保持包名及签名一致，不先卸载。

本轮不包含地点搜索、设备定位、自动路线优化、实时路况、收费估算、天气、AI、费用、协作、云同步或离线地图下载。
