# 在途 Onway

v0.6.0 个人旅行工具：独立收藏地点、按天安排多个行程、逐段选择自驾／步行／公共交通并记录车次、航班，并在 Android 上打开高德导航。Web 与 Android 共用 React 界面，各自保存本地数据，不连接 TREK 或业务后端。

## 开发与构建

需要 Node.js 24、npm 11。

```powershell
npm ci
npm run dev
npm run check
npm run format:check
npm run android:debug
```

开发页面为 [http://127.0.0.1:5175/#/today](http://127.0.0.1:5175/#/today)。localhost 与 127.0.0.1 是不同的 IndexedDB 存储来源。

Android 最低 **Android 12 / API 31**。版本 **0.6.0 / versionCode 7**，包名 `app.onway.personal`，Debug APK 位于 `artifacts/onway-debug.apk`。

## 使用

- **总览**：显示当天安排；日期未定或不在行程期间时显示首日预览，默认三个地点，可展开。个人备注独立保存，离页可保存并继续或放弃并继续。
- **地图**：查看当前行程，点选新增、编辑和重新选点，也可输入坐标、搜索地点。全部视图默认保存到未安排，按天筛选则保存到当天。
- **计划**：桌面左侧编排、右侧地图与添加地点；手机以行程为主，地图在页内打开。日期下拉定位并展开当天，保留其他日期标题。支持手柄拖动、跨天移动、单次撤销和锁定位置的连续添加；交通点击后展开快捷方式。删除一天仍将地点移回未安排，至少保留一天。
- **地点**：无需行程即可收藏、编辑、分类，按名称／地址筛选和地图查看；加入行程时生成独立副本，之后修改或删除库中的地点不影响行程。行程地点也能单独收藏入库。

每个地点一个分类。预置景点、餐饮、住宿、停车、机场、车站；旧“交通”分类保留为“交通（待整理）”，不自动猜分。可新增、重命名或删除自定义分类。删除分类会将库与行程中的引用改为未分类，不删除地点。

手动坐标采用十进制度，**经度在前、纬度在后**；可以在经度框粘贴一对坐标。来源选 GPS／OSM（WGS84）或高德（GCJ-02）。通过本地 `gcoord` 转换统一保存为 WGS84，不调用转换 API。已保存地点再次编辑显示其 WGS84 坐标。

## 地点搜索

地图页直接显示搜索框，地点库通过“搜索新地点”打开搜索；“地图服务设置”可管理供应商与 Key。地点库默认紧凑列表，可切换网格，地图默认收起。收藏筛选与当前滚动位置在本次会话内保留。

- **OpenStreetMap / Nominatim** 无需 Key，可在设置中选用。手动按钮或回车查询，不输入即搜。请求串行，公共服务请求开始间隔至少 1.1 秒，15 秒超时，不自动重试。服务地址可以改为兼容 Nominatim 的 HTTPS 地址。
- 本次个人构建默认 **高德地图**，已经预置用户提供的 **Web 服务**类型 Key，打开即可搜索。“地图服务设置”支持修改 Key、切换服务及恢复构建默认配置；设备保存的选择优先。Android SHA1 绑定 Key 不能用于此 HTTP 接口。
- 默认值来自被 Git 忽略的 `.env.local` 中的 `VITE_AMAP_SEARCH_KEY`，模板见 `.env.example`。未配置私有默认值的新构建使用 Nominatim。真实 Key 不提交 Git，但按用户要求会进入当前 Web／APK 构建资源；这是个人构建默认值，不是服务端密钥保管。设备修改只保存在本机。
- 每次最多 10 个结果。查询只在选定服务中进行，不自动切换；查询词发送至所选服务，自己的地点备注不会随搜索提交。
- 两个提供方各缓存最近 50 个查询、有效期 24 小时，重复查询可减少请求。高德配额由账户和服务权限决定，Onway 无法显示实时余量；在控制台查看。配额、Key 或连接异常明确提示；高德瞬时限流延迟 2 秒重试一次，其余错误不自动重试。
- 选中结果后仍需确认名称、分类、地址与所属天并保存；取消不产生地点。高德结果本地转换为 WGS84，保留供应商、POI ID 和城市编码。修改位置后清除旧位置来源及城市信息，公交需要时按新坐标识别。

官方说明：[Nominatim 使用政策](https://operations.osmfoundation.org/policies/nominatim/)、[高德搜索 API](https://lbs.amap.com/api/webservice/guide/api/search/)。公共 Nominatim 的整体应用流量仍须遵守政策；公开分发或多人使用前应安排自有服务或合适供应商。

## 路线与导航

一天至少两个已安排地点后，在相邻地点之间编辑交通。每段默认“自驾／高德”，可选步行、公共交通、火车或飞机；火车与飞机在详情中手动记录已确定的信息。自驾可手动切换 [FOSSGIS 公共 OSRM](https://routing.openstreetmap.de/about.html)。各天独立，不连接前一天终点，也不自动调整地点顺序。

- 新增地点、排序、展开收起和切换日期不自动算路；改变已有路段的交通查询条件后，600ms 合并连续操作。详情可保存并查询且留在面板查看结果，支持单段和当天刷新；启动、切换页面、恢复备份不全量重算。
- 高德搜索、城市识别及路线共用队列：请求开始间隔至少 550ms、最多两个在途请求。瞬时限流延迟 2 秒重试一次，配额和 Key 错误不重试。OSRM 独立串行、至少 1 秒间隔、20 秒超时、不自动重试。
- 公共交通提供推荐、地铁优先、少换乘。今天可以“现在出发”，其他日期须明确出发时间；时间按北京时间填写，不从前一段推算。缺少城市编码时自动按坐标识别，失败可重试，不猜测城市。
- 首条公交候选标为推荐，用户采用后保存正式方案。刷新只更新候选；地点、时间变化后旧方案待确认，须重新选择或明确核对原方案后继续使用。公交总耗时已包含方案内换乘及步行，不重复累加。
- 火车手动填写车次与站点，飞机手动填写航班号与机场，两者均保存出发／到达日期时间，可跨午夜；按出发所属天统计时长，距离标为未知。主动切换火车、飞机可沿用已有字段后核对保存；修改行程日期不改写已确定时间。
- 排序、跨天移动或删除地点／一天后，失去关系的交通记录保存在行程的“待关联交通”；重新关联并核对后使用，未关联时不计入汇总。删除整个行程会一并删除其交通记录。
- 驾车和公交候选缓存 5 分钟，步行与 OSRM 为 24 小时；过期结果标为上次估算。失败保留仍匹配的旧结果，缓存写入失败可单独重试保存。当天显示已有结果段数，缺失及待确认段明确标为部分汇总。
- 地图沿用按天配色，线型辅助区分方式；仅绘制接口提供的有效几何，铁路缺少几何时不补直线。旧整日 OSRM 缓存仍可显示为“旧版自驾估算”，有新版分段结果后不重复汇总。

路线查询发送两端坐标，以及公交必要的城市编码、策略和出发时间；个人备注留在本机。搜索供应商独立于路线来源，选择 OSM 搜索仍可用已保存高德 Key 算路。高德失败不会自动切换 OSRM。接口说明：[高德路径规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)。

估算不包含地点停留时间。Android 的“高德驾车导航”打开手机高德并传递单个已保存目的地，Onway 不读取设备定位；此导航 URI 不需要 Web 服务 Key，实际导航以高德为准。

## 文件备份与恢复

顶部“备份”入口提供导出和恢复，四个主导航不变。

- JSON 备份包含全部行程、每天地点的顺序、地点库、自定义分类、交通设置、已选公交方案、手动车次与航班、待关联记录及个人备注，保留 ID 和独立副本关系。文件格式版本为 1，记录导出时间及应用版本，最大 20 MB。
- Web 发起文件下载；Android 使用系统文件选择器保存到用户选择的位置，也可从该选择器读取文件。两端格式相同，支持手动传输后互相恢复。
- 导入先校验版本、数据结构、坐标、分类引用和重复 ID，再展示当前与备份的数据量。勾选并确认后整体替换，不执行合并。取消、无效文件或保存失败不会改变原数据。
- 可在确认页面先导出当前数据。恢复期间发现本地内容已更新时，必须重新读取预览，避免覆盖新修改。
- 搜索配置与 Key 留在当前设备，不进入文件；搜索缓存不备份，恢复保留当前搜索缓存。候选路线缓存不备份，恢复时清空；正式已选方案、手动车次与航班保留，缺少的候选可按天重新计算。
- 文件是可读 JSON。恢复成功后刷新应用内数据，不要求重新加载网页资源；Web 离线冷启动限制保持不变。
- “编辑收藏地点”和“编辑行程地点”现在使用不同标题，后者同时显示所属行程。

## 本地数据与离线

- Web：当前浏览器来源的 `onway-local` IndexedDB；Android：应用私有目录 `onwaySQLite.db`。两端数据独立，可通过备份文件互相转移，无账号或云同步。
- 数据库表结构仍为 v1，旧个人备注键 `demo.travel-note` 不变。旅行文档 `travel.workspace` 为 **schemaVersion 4**，包含城市、交通记录、航班及机场／车站分类；读取 v1／v2／v3 时只在内存迁移，下一次成功保存才写入 v4。旧行程、ID、顺序和备注保留，不自动收藏或创建示例。
- `routes.cache` 为文档 v2，兼容旧整日缓存 v1。搜索配置和缓存是独立键，不混入行程或路线缓存。
- 保存成功后才更新共享页面；失败保留输入，读取损坏文档不清空数据。Web 写入继续使用过期快照检查与可用时的 Web Locks。
- APK 内置页面，断网可编辑已有行程、地点库、分类、坐标与备注，读取已保存路线；在线搜索与重新算路需要网络。
- 底图使用 MapLibre GL JS + OpenFreeMap Positron，保留地图署名；不支持离线地图下载。底图失败不阻塞列表和手动坐标操作。
- Web 无 Service Worker，不保证离线冷启动或首次加载尚未下载的按需模块。
- 覆盖安装保持签名及包名一致；卸载或清除应用／网站数据会删除本地资料。

不包含设备定位、自动路线优化、实时导航、收费展示、票务查询、天气、AI、费用、协作或应用商店发布。
