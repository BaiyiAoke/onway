手机厂商限制 ADB 模拟触摸（INJECT_EVENTS），因此编辑、点击和返回操作由用户在手机完成；电脑负责安装、启动、强制重启、截图及数据库核对。没有绕过手机的权限限制。

APK 只申请联网权限及 AndroidX 自动生成的本应用签名级接收器权限；SQLite 插件附带的生物识别权限已在合并清单中移除。无定位权限，无 server.url、电脑 IP 或外部开发服务依赖。
