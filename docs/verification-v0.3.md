## 自动化覆盖

- 两点和多点请求顺序、1 公里吸附范围、逐段映射、几何与数值校验。
- NoSegment、NoRoute、TooBig、畸形响应、20 秒超时、断网及 429 限流。
- 请求串行、开始间隔至少 1 秒、取消排队请求、不自动重试。
- 改名和备注不失效；排序、坐标、增删地点失效；缓存重读、损坏文档不覆盖、旧备注／旅行文档保持原文。
- 地点输入变化、删除天或切换行程后，晚到响应不会保存或显示成当前路线。
- 缓存写入失败保留未保存结果，重试只写本地；重新算路失败仍可显示上次匹配估算。
- 地图每一天独立 feature，全部不跨天连线，筛选／失效清空图层数据而不重建地图。
- 高德名称编码、WGS84 dev=1、应用来源、未安装／打开失败提示，以及 Web 隐藏按钮。
