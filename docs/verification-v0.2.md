## 数据与错误处理测试

39 项测试覆盖原有存储，以及新增模型、仓库、Context、编辑面板、地图和今天页：

- 启动不生成示例行程，显式示例使用独立 ID，原个人备注键 demo.travel-note 不变。
- 单键 travel.workspace 整体写入；串行保存以最近成功快照为准，失败不发布新状态、不清空输入，重试可继续。
- 未安排与每天之间移动保留地点 ID，不丢失、不重复；同组编辑保留顺序，删天依序移回未安排，至少保留一天。
- 多行程互不覆盖，删除当前行程后选择剩余行程。
- 未定日期、闰日、跨月、跨年与今天匹配；修改出发日期不删除地点。
- 拒绝损坏 JSON、不支持的文档版本、重复 ID、越界坐标和无效引用，读取错误不覆盖原文档。
- 多标签旧快照冲突在编辑面板显示具体原因；重新读取后草稿、其他页面新增数据均保留。目标行程已被删除时保留输入，不自动重建。
- 取消与返回确认、继续编辑、明确放弃、个人备注保存期间拦截退出。
- 地图加载或失败时不采集坐标，清单仍可编辑；点标记不触发新增，同一行程重新读取保留草稿和地图实例。

## 交付与限制

- 新增及修改文件见 [工程文件清单](file-inventory.md)，使用方式见 [README](../README.md)、[架构说明](architecture.md) 和 [Android 指南](android.md)。
- v0.2 功能实现、工程检查、Web 验证及 Android 12 核心验收完成；本轮没有未完成的功能项。手机的根页面退出沿用 v0.1 逻辑，本轮重点复测新增编辑与返回确认行为。
- APK 与缓存被忽略，源码提交情况以 Git 记录为准。开发服务在独立运行验证后恢复为 http://127.0.0.1:5175/。
- 自驾算路、距离耗时、地点搜索、定位、云同步、文件导入导出、离线地图不在 v0.2 范围内。
- Web 与 APK 各自保存数据。系统强制结束进程会丢失未保存草稿，卸载或清除应用数据会删除本地资料。
