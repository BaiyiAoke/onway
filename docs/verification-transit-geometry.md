# 公共交通线路几何修复验证

日期：2026-09-18。版本保持 0.6.0／versionCode 7。本地提交范围包括计划编排、高德底图及本次几何修复，不推送远端。

## 原因与改动

高德公交 2.0 的步行接驳、公交和地铁步骤实测把坐标串放在 polyline.polyline，原解析只接受直接字符串，导致方案距离和耗时正常，但线路数组为空。

- src/services/routes/amap.ts：同时接收字符串与单层嵌套对象，继续转为 WGS84 并验证有效坐标。拒绝空坐标被 Number 转成 0；不补画缺失的铁路区间。
- src/services/routes/amapSegments.test.ts：增加真实响应结构的公交、地铁、步行接驳解析以及已选方案进入地图数据的回归；覆盖既有自驾／步行格式、无效嵌套几何和缺失铁路几何。
- docs/file-inventory.md、本文：改动清单、实网与安装包验证记录。

原有查询、缓存、方案选择和备份规则保持不变；本轮未增加火车／飞机示意连线。
