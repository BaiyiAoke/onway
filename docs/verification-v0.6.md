## 自动检查

- `npm run check` 通过：类型检查、ESLint、22 个 Vitest 文件、125 项测试、生产构建均通过。

## 浏览器验收

本地 Vite 预览使用真实应用流程检查：

- 启动、切换页面和恢复备份不触发全量自动算路。
- 自驾、步行、公共交通混合路段可独立查询与汇总，单段失败时保留部分汇总。
- 公交城市补齐、候选预览、正式方案选择和刷新后保护均通过。
- 手动车次支持跨午夜，离线状态可继续查看和编辑。
- 重排地点后，已确定交通进入待关联记录，可查看并保留原地点快照。
- Web 备份包含 v3 行程、已选方案和车次记录，不包含高德 Key 或候选缓存。
- 360px、390px 与桌面宽度未发现横向溢出。

浏览器检查结果保存在 `artifacts/v0.6/browser-results.json`。

## Android 验收

- 构建目标：`0.6.0 / versionCode 7`，包名 `app.onway.personal`，最低 Android 12 / API 31。
- 覆盖安装前已备份设备 SQLite；原 v0.5.x 行程、地点库、备注、地图服务设置和 Key 在升级后保留。
- 已在 Android 12 真机上覆盖安装并核对版本号：`versionName=0.6.0`、`versionCode=7`。
- 真机 WebView 流程通过：添加临时三点后实际触发高德自驾、步行、公交与城市识别，Android 返回键拦截未保存修改，断网状态下保存跨午夜手动车次。结果见 `artifacts/v0.6/device-flow-results.json`。
- Android 系统文件选择器导出备份成功；选择刚导出的 JSON 恢复成功，恢复后计划页可见临时行程、公共交通与 `G123` 车次。
- 验收完成后通过应用界面删除临时行程，并清理本次导出的临时备份文件；复核临时行程、验收地点和 `G123` 均未残留，原正式行程仍存在。
